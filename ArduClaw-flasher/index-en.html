How It Works

> You:
"receive data from mqtt topic home/light
if payload on turn on LED at pin 27,
if off turn it off,
and save permanently
> AI Agent:
OK: mqtt.subscribe topic=home/light
action=gpio.write pin=27 value={PAYLOAD}
Saved in NVS — survives even if ESP32 is powered off.

You say what you want to happen — in Indonesian or English. The AI Agent on the ESP32 translates it into real actions.

Create if/else logic, subscribe to MQTT, read sensors, control GPIO — all from chat, no C++ required.

Everything is automatically saved in the ESP32's NVS. Reset as many times as you want — your logic stays.

Why ArduClaw?

There's already ESP-Claw from Espressif — so why build another one?

ESP-Claw is powerful, but limited — it only runs on specific boards like ESP32-S3. Affordable boards like ESP32-WROOM, ESP32-C3, or ESP32 with < 1MB RAM are not supported.

ArduClaw changes that. Still in beta — currently supports the ESP32 DEV boards that are widely available. Support for other boards is coming.

“This changes how we code ESP32 — from writing digitalWrite(27, HIGH) to just saying turn on the light at pin 27.”

ESP32 DEV Board

Supports the most popular ESP32 DEV boards (WROOM, DevKitC). Beta, more boards coming.

Logic & MQTT

Create if/else logic, subscribe to MQTT, read sensors — all via chat without manual coding.

Persistent (NVS)

All config & logic is saved to NVS — survives ESP32 resets and power cycles.
