Kamu bilang apa yang mau terjadi: dalam bahasa Indonesia atau Inggris. AI Agent di ESP32 yang nerjemahin jadi eksekusi nyata.

Bikin logika if/else, subscribe MQTT, baca sensor, kontrol GPIO: semua dari chat, tanpa nulis C++.

Hasilnya tersimpan otomatis di NVS ESP32. Reset berkali-kali pun logic tetap jalan.

Kenapa ArduClaw?

Sudah ada ESP-Claw dari Espressif: kenapa bikin lagi?

ESP-Claw memang canggih, tapi terbatas: hanya berjalan di board tertentu seperti ESP32-S3. Board ESP32 murah seperti ESP32-WROOM, ESP32-C3, atau ESP32 dengan RAM < 1MB tidak didukung.

ArduClaw hadir untuk mengubah itu. Masih beta: saat ini baru support board ESP32 DEV yang paling banyak dijual di pasaran. Ke depannya akan dikembangkan untuk board ESP32 lain.

“Ini bakal mengubah cara ngoding ESP32: dari nulis digitalWrite(27, HIGH) jadi cukup bilang nyalakan lampu di pin 27.”

ESP32 DEV Board

Support board ESP32 DEV paling populer (WROOM, DevKitC). Masih beta, board lain menyusul.

Logika & MQTT

Bikin logika if/else, subscribe MQTT, baca sensor: semua dari chat tanpa coding manual.

Persisten (NVS)

Semua konfigurasi & logika tersimpan di NVS: gak hilang meski ESP32 di-reset atau dimatikan.

Flash < 1 Menit

Flash firmware via Web Serial, setup WiFi & LLM dari browser. Siap pakai dalam hitungan menit.
